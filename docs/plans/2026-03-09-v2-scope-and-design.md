# SoundCanvas 第二版范围与设计

> 设计日期：2026-03-09  
> 状态：待确认  
> 前置：第一版设计见 `2026-02-28-music-learning-sandbox-design.md`

## 1. 第二版范围说明

第二版在第一版（认证、学习路径、编曲沙盒、我的作品）基础上，扩展沙盒能力、音色与导出、学习与沙盒联动、风格路线深化、内容可配置与播放性能。**本版不做**：个人中心、作品公开/分享、第三方登录（用户与作品侧功能留待后续版本）。

---

## 2. 沙盒能力增强

### 2.1 撤销 / 重做

- 沙盒内对 `content` 维护历史栈（建议最多 20 步）。
- 支持快捷键：Ctrl+Z 撤销、Ctrl+Shift+Z 重做；工具栏提供对应按钮。
- 每次「会改变 content 的操作」压栈（节奏/和弦/旋律编辑、BPM/小节数变更等）；保存、加载、重置不压栈。
- 实现要点：`src/lib/sandbox-history.ts` 或于沙盒页内 useReducer + 历史数组；深拷贝 content 再入栈，避免引用污染。

### 2.2 小节数可调

- 第一版固定 8 小节；第二版支持用户选择 4 / 8 / 16 / 32 小节。
- 增加小节数：和弦轨、旋律轨未填的小节保持空；节奏轨 pattern 保留，超出新 bars 的 chord/melody 可截断或提示。
- 减少小节数：超出部分的 chord、melody 丢弃；rhythm.pattern 中 beat 超出新总拍数的丢弃。
- UI：沙盒顶部或轨道旁提供「小节数」下拉或步进器。

### 2.3 BPM 与节拍器

- BPM 范围：例如 60–180，输入校验与步进按钮（+5 / -5）。
- 可选节拍器：播放时按拍子发出 click 声（可仅强拍或每拍），便于跟拍；可单独开关（如「仅节拍器」预览）。
- 节拍器音色：简单正弦或短促噪声，通过 Web Audio 合成即可。

## 3. 沙盒音色扩展

### 3.1 节奏轨

- 在现有 kick、snare 基础上增加：hi-hat（开/闭可选或统一）、clap；至少 4 种可选的「鼓类型」。
- 数据格式：`rhythm.pattern[].type` 扩展为 `"kick" | "snare" | "hihat" | "clap"`（或更多），旧作品兼容：未知 type 按 snare 或静音处理。
- 音源：采样文件放 `public/samples/` 或通过 Web Audio 合成；统一由音频引擎按 type 播放。

### 3.2 和弦轨 / 旋律轨

- 提供 2～3 种「音色」可选（如钢琴、电钢琴、合成 pad），用户可在轨道旁或全局选择。
- 数据格式：在 `ProjectContent` 中增加可选字段，如 `chordVoice?: string`、`melodyVoice?: string`，默认对应第一版音色。
- 播放：音频引擎根据 voice 选择不同 Oscillator 类型或采样；若用采样需预加载对应集合。

## 4. 导出

### 4.1 导出为音频（WAV / MP3）

- 使用 Web Audio 的 OfflineAudioContext：按当前 content 与 BPM 从头渲染整段，输出 AudioBuffer，再转为 WAV（或通过库转 MP3）。
- 导出长度 = 当前小节数 × 每小节时长（由 BPM 与 4/4 计算）。
- UI：沙盒内「导出」按钮，可选「WAV」或「MP3」（若引入编码器），触发下载。

### 4.2 导出为 MIDI（可选）

- 将 rhythm / chords / melody 转为 MIDI 事件（节奏轨映射到鼓通道，和弦/旋律映射到不同通道或轨道）。
- 使用库（如 tonejs/midi 或 midi-writer-js）生成 .mid 文件并下载。
- 若第二版时间紧张，可先只做 WAV，MIDI 列为后续迭代。

## 5. 学习与沙盒联动

### 5.1 「在沙盒中练习」入口

- 在节奏、和弦、旋律学习页以及各风格子页增加按钮/链接：「在沙盒中练习」。
- 跳转至 `/sandbox`，并通过 query 或 state 传入「预设标识」，例如 `?preset=chords-1645`、`?preset=style-guofeng`。
- 沙盒加载时：若存在预设参数，则用预设 content 初始化（不覆盖已有未保存内容时可先 prompt 或直接应用）。

### 5.2 预设内容来源

- 预设为前端定义的若干份 `ProjectContent` JSON，或从静态配置/API 读取（见「学习内容可配置」）。
- 示例：`chords-1645` 对应 C-Am-F-G 四小节循环；`rhythm-basic` 对应简单 4/4 鼓点；各风格预设对应风格化节奏型 + 和弦进行 + 可选旋律片段。

## 6. 风格路线深化

### 6.1 风格化沙盒预设

- 进入沙盒时可选「从风格入门」：用户选择国风/爵士/RnB/日系/电子/配乐等，沙盒用该风格的默认节奏型、和弦进行、音色预设初始化。
- 与 5.2 共用预设数据结构；风格入口可带 `?preset=style-{id}`。

### 6.2 风格关卡 / 小任务

- 每条风格下 3～5 个小任务，例如：「用 1645 做 4 小节」「加一条简单旋律」「模仿示例节奏型」。
- 任务描述与验收规则可先做简单版：仅「完成 N 小节」「包含某和弦」等，由前端根据当前 content 做简单校验；不做复杂评分与排行榜。
- UI：风格子页内「任务」列表，点击任务可跳转沙盒并注入任务所需预设或提示文案。

### 6.3 风格示例曲 / 模板

- 每条风格提供 1～2 个系统模板（只读），用户可在「我的作品」或风格页「用模板创作」将模板克隆为本人作品再编辑。
- 实现：模板存为静态 JSON 或数据库中的「系统作品」（无 userId 或标记为 template）；克隆 = 复制 content 后 POST 为当前用户新作品。

## 7. 学习内容可配置与示例音频

### 7.1 学习内容可配置

- 节奏/和弦/旋律/风格页的文案与结构改为由配置驱动：如从 Markdown 文件或 JSON 配置读取，而不是写死在组件内。
- 第二版可先做「从本地 MD 或 JSON 读」；不强制上 CMS，便于后续替换为 API/CMS。

### 7.2 示例音频统一管理

- 学习页与风格页的示例音频路径统一来自配置（如 `content/config/learn-audio.json` 或按章节命名的静态文件清单）。
- 播放组件统一从配置取 URL，便于替换与扩展；若有 CDN 后续只改配置即可。

---

## 8. 播放与性能

### 8.1 预加载

- 沙盒播放前：根据当前 content 用到的 rhythm 类型、音色，预加载对应采样或初始化合成节点。
- 可在沙盒页 mount 或首次点击播放时触发预加载；预加载完成后再 start 播放，避免首击卡顿。

### 8.2 大作品

- 小节数 16/32 时，避免一次性解码过多采样；按需解码或复用 buffer。
- 播放调度按「当前时间窗口」计算即将触发的事件，避免一次性生成过多定时器。

## 9. 数据格式扩展（第二版）

在原有 `ProjectContent` 上扩展，保持向后兼容：

- `bars`: 允许 4 / 8 / 16 / 32（第一版仅 8）。
- `rhythm.pattern[].type`: 增加 `hihat`、`clap` 等。
- 可选 `chordVoice`、`melodyVoice`（字符串，如 `"piano"`、`"epiano"`、`"pad"`）。
- 保存/加载时旧数据缺省字段用默认值（如 bars=8，voice=默认音色）。
